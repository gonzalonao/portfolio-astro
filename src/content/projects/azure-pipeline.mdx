## Overview

A production-style medallion pipeline moving raw operational data through standardized **Bronze → Silver → Gold** layers, with the Gold layer feeding a Power BI semantic model used for executive reporting. Built end-to-end during the ESESA Master's program.

<Mermaid code={`flowchart LR
  S[Source<br/>SQL / Files / API] --> ADF[Azure Data Factory<br/>orchestration]
  ADF --> B[Bronze<br/>raw, append-only]
  B --> SI[Silver<br/>cleaned, conformed]
  SI --> G[Gold<br/>star schema]
  G --> F[Microsoft Fabric<br/>Lakehouse]
  F --> PBI[Power BI<br/>semantic model + DAX]`} />

## Bronze — Raw Capture

Azure Data Factory pipelines land source data verbatim into Blob Storage / Lakehouse in append-only Parquet, partitioned by ingest date. No transformations — the goal is auditability and replayability.

## Silver — Conformed

PySpark notebooks in Microsoft Fabric apply schema enforcement, type coercion, deduplication, and slowly-changing-dimension handling. Output is a set of cleaned, business-key'd tables ready for modeling.

## Gold — Star Schema

Fact and dimension tables modeled for analytics, with surrogate keys, role-playing dimensions, and pre-aggregated measures where they meaningfully accelerate BI queries.

## Power BI Semantic Layer

DAX measures and calculation groups expose the Gold layer to business users. Examples: time-intelligence (YoY, rolling 12-month), dynamic format strings, and a calculation group that switches between gross/net measures with a single slicer.
