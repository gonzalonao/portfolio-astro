## Overview

A growing collection of supervised and deep-learning projects built during the ESESA Big Data & AI Master's program. The aim is a portfolio of clean, reproducible notebooks with consistent experiment tracking and clear write-ups, rather than a single deliverable.

## Coverage

- **Classical supervised learning** — linear and logistic regression, Random Forest, gradient boosting; emphasis on feature engineering, cross-validation, and interpretability (SHAP / permutation importance).
- **Deep learning fundamentals** — feed-forward and convolutional networks in PyTorch, training loops written from scratch, regularization and learning-rate scheduling.
- **Sequence models** — LSTM and GRU networks for time-series forecasting and text classification, with comparisons against simpler baselines.
- **Computer vision** — CNN architectures for image classification, transfer learning from pretrained backbones.

## Stack

scikit-learn, PyTorch, pandas, numpy, matplotlib, Jupyter.

## Status

Ongoing — new notebooks are added as the program progresses. The repository structure is consistent across projects: `data/`, `notebooks/`, `src/`, `models/`, with a top-level `README` summarizing each experiment.
