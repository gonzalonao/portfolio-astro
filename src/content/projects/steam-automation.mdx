## Overview

Built an end-to-end ecosystem for investment and portfolio management in Steam's secondary digital asset market, scaling from minimal initial capital to exponential growth in managed asset volume. The system combines real-time market scraping, async order execution, and a BI layer for portfolio monitoring.

## Software Engineering (Async Python)

Extended the `steampy` library to support async requests (`asyncio`, `aiohttp`), achieving critical reduction in buy-order execution latency. Replacing the blocking sync calls with a coroutine-based execution loop made it possible to monitor hundreds of items concurrently and capture pricing windows that closed in under a second.

## Network Architecture

Implemented a rotating proxy system and session management to bypass rate-limiting and ensure high availability of monitoring bots. Each session pool tracked cookie state, request budgets, and cooldowns independently, with automatic failover when an IP got throttled.

## ETL & Web Scraping

Advanced Selenium and BeautifulSoup scripts for real-time data extraction and consolidation into proprietary databases for trend analysis. Headless Chromium drove the parts of the UI that required JavaScript; static market endpoints were parsed directly with `BeautifulSoup` for speed.

## Business Intelligence

Created a financial control dashboard using Power Query (M) and Excel for automated KPI tracking — realized P&L, holding periods, exposure by asset class, and rolling ROI. The Power Query layer normalized heterogeneous CSV exports into a single tidy fact table consumed by the dashboard.

## Frontend Automation

JavaScript / Tampermonkey scripts for UI optimization and repetitive workflow automation — auto-confirming trades, batching listings, and surfacing pricing context inline on the Steam web UI.
