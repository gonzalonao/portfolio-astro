## What this is

Bilingual (EN/ES) personal portfolio site: Astro 5 + MDX content collections, Tailwind,
React islands, KaTeX + Mermaid in articles. Production: <https://gonzalonao.vercel.app>
(Vercel deploys `main`). Node ≥ 22.12.

## Branching — lightweight main-flow (documented deviation)

This repo has no `develop`: `feat/*` / `fix/*` branches off `main`, PR into `main` =
review gate, Vercel deploys `main` on merge. This deliberately deviates from the three
workspace models — the site is small and Vercel tracks `main` directly. Conventional
Commits as everywhere; never merge to `main` without Gonzalo's approval.

## Layout (the parts that matter)

```
src/content/projects/     EN project entries (.mdx)   ─┐ same filenames, same
src/content/projectsEs/   ES mirrors                   ─┘ frontmatter keys
src/content/writing/      EN articles                  ─┐ same mirror rule
src/content/writingEs/    ES mirrors                   ─┘
src/i18n.ts               UI strings incl. hero.roles typer phrases (EN + ES)
src/layouts/BaseLayout.astro   default <title> + meta description (EN + ES)
public/og.png             social-share card — titles are BAKED IN (see gotchas)
public/cv*.pdf            CV downloads — generated artifacts (see gotchas)
```

## The EN/ES mirror rule

Every entry in `projects/` and `writing/` has a same-named twin in `projectsEs/` /
`writingEs/` with the same frontmatter keys. **Run `npm run check:i18n` before
committing any content change** — it flags missing twins and frontmatter drift
(`scripts/check-i18n-sync.mjs`).

## Gotchas

- **`public/og.png` titles are baked into the image.** Changing the role line/titles
  anywhere means re-rendering og.png too (design notes in `../TODO.md`).
- **CV PDFs are generated by the jobsearch CV builder** — regenerate there
  (`jobsearch/CVs/build_cv.py`), never edit `public/cv*.pdf` in place.
- **Canonical role line**: `src/i18n.ts` `hero.roles`, BaseLayout meta, og.png, CV PDFs,
  and the GitHub/LinkedIn headlines must all agree — when one changes, sweep the rest
  (tracked as `../TODO.md` item 3).

